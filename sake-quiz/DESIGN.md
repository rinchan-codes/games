# 日本酒クイズ 設計メモ

タイトル：未定。仮に「酒どころ手帖」。

## 何をするゲームか

全国の日本酒の銘柄・蔵元・産地を4択クイズで覚える。正解した都道府県に印が押され、47都道府県の手帖が埋まっていく。

1回10問。3分前後で終わる。
理由：飽き性でも1回は遊び切れる長さ。埋まっていく手帖が「もう1回」の理由になる。

## 対象

全47都道府県。各県2銘柄を目標（別の蔵）。仮置き。
- 鹿児島・沖縄は清酒蔵が少ない。1銘柄でも可。0なら県ごと外す前に林に相談。
- 1県1銘柄も確認できなかった県が出たら、その時点で報告。

## 載せるデータ

1銘柄につき：
- 銘柄名・読み
- 蔵元の会社名
- 都道府県・市町村
- 創業年（公式に明記があるときだけ）
- 特徴メモ1つ（仕込み水、使う米、名前の由来など。公式で確認できたものだけ）
- 出典URL

確認できない項目は持たない（null）。null の項目を使う問題はその銘柄では出さない。
理由：推測で埋めると、知るためのゲームとして意味がなくなる。

### 裏取りのルール
- 蔵元公式サイトが第一。次に日本酒造組合中央会、県の酒造組合。
- まとめサイト・通販・Wikipedia は候補探しにだけ使う。裏取りには使わない。
- 廃業・休業・銘柄譲渡・統合があったものは使わない。
- 使ったURLは全部 sources.md に残す。確認日も書く。
- 解説文は自分の言葉で。公式の文章を写さない。

## 問題の種類

| 種類 | 問い | 選択肢 |
|---|---|---|
| 産地 | この銘柄はどこの県？ | 都道府県4つ |
| 県の酒 | ○○県の酒はどれ？ | 銘柄4つ |
| 蔵元 | この銘柄を造る蔵は？ | 蔵元4つ |
| 町 | この蔵があるのは？ | 市町村4つ |
| 古さ | 創業が古いのはどっち？ | 銘柄2つ |

- 誤答の選択肢は自動生成。
  - 県の酒：同じ県の銘柄は誤答に入れない（正解が2つになる）。
  - 町：同じ県の別の市町村を優先して混ぜる。足りなければ近い地方から。理由：県が違うと町名だけで消去できてしまう。
  - 古さ：創業年の差が10年未満の組は出さない。理由：曖昧な問題を避ける。
- 産地の誤答は同じ地方の県を2つ混ぜる。理由：全国バラバラだと簡単すぎる。
- 回答後に解説カードを出す（蔵元・所在地・創業・特徴・出典リンク）。

## モード

- 全国：47都道府県からランダム10問。
- 地方：北海道・東北／関東／中部／近畿／中国・四国／九州・沖縄から1つ選んで10問。
- まだの県：手帖で印がない県だけから出す。空いた穴を埋めに行ける。

難易度切り替えは置かない。理由：10問で終わる遊びに設定画面は重い。

## 手帖（進行）

- 47マスのタイルマップ。地図の形をざっくり再現したグリッド。
- その県の問題に1回でも正解すると印。
- 印をタップすると、その県の銘柄カードが見られる（図鑑）。
- 保存は localStorage。try/catch で包む。使えない環境では保存せずに遊べる。

## 見た目

ベタな和風（金と黒、毛筆）は避ける。

方向：旅先で使う手帖・きっぷ。
- 地は生成りの紙色。文字は墨ではなく濃い藍。
- 差し色は朱1色。正解の印だけに使う。
- 書体：UIは Zen Kaku Gothic New、銘柄名だけ Shippori Mincho。毛筆体は使わない。
- 罫線と余白で組む。グラデーション・影は控えめ。
- 紫グラデ、Inter、絵文字見出しは使わない。
- ダークモードあり（夜の紙：濃紺地に生成り文字）。

「お酒は20歳になってから」：画面右下に小さく固定で1つ。

## 画面

1. タイトル：モード3つ＋手帖ボタン。進み具合（○/47）。
2. 問題：問番号、問い、選択肢。PCはキー1〜4でも答えられる。
3. 解説：正誤、銘柄カード、次へ。
4. 結果：○/10、今回新しく印が付いた県。
5. 手帖：タイルマップ＋県カード。

400px幅で1列に落とす。横スクロールなし。タイルマップはマスを縮めて収める。

## 実装

- HTML1ファイル（sake-quiz/index.html）。外部 fetch なし、外部画像なし。
- 外部スクリプトなし。素のJS。Google Fonts のみ読む。
- データはHTML内の `<script type="application/json" id="sake-data">` に置く。検査スクリプトから読みやすいように分ける。
- alert/confirm/prompt は使わない。手帖リセットの確認もゲーム内UI。

  - null の項目を使う問題が出ていないか。
  - 出典URLが全銘柄にあり、sources.md に載っているか。
