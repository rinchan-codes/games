# 出典

index.html に載せた事実の裏取りに使ったURL。

- 蔵元公式サイトが第一。足りないところは日本酒造組合中央会・府県の酒造組合・官公庁（国税庁・酒類総合研究所・県庁など）の資料で補った。
- 創業年は公式に「創業」として年が明記されているものだけ載せた。設立・株式会社化・酒造り開始の年や、表記が食い違うものは載せていない（ゲーム内でも出題しない）。
- 読みがなは公式サイトで仮名かローマ字の表記を確認できたものだけ。
- 代表酒のスペック（度数・日本酒度・酸度・精米歩合・使用米）は蔵元の商品ページに書かれた値をそのまま載せた。
- 廃業・休業・銘柄譲渡・事業譲渡・統合は、全銘柄について検索で確認した。該当したものは載せていない。
- 解説・メモは公式の文章を写さず、書き直した。

### 候補にしたが外した銘柄

- 統合・移転・譲渡にあたる、またはその可能性があるため: 一ノ蔵（宮城、4蔵の合併で発足）、写楽（福島、銘柄が別の蔵へ移った）、銀盤（富山、経営譲渡）、杵の川（長崎、4蔵合併と移転）、酔鯨（高知、新しい蔵へ製造拠点が移った）、玉乃光（京都、蔵の移転歴）
