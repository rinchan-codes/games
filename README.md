# games

## 武器ガチャ（weapon-gacha）

アイスボーンの武器縛り用に、14武器種からランダムで使用武器を決めるガチャサイト。

- 公開URL（GitHub Pages有効化後）: https://rinchan-codes.github.io/games/weapon-gacha/
- 1〜4人同時抽選（武器被りなしオプション）
- 武器の除外設定 / 近接のみ・遠距離のみプリセット
- レアリティ演出（★3蒼・★4紫・★5金）、★5で追加縛りオプション
- 履歴と武器ごとの使用回数（ブラウザ内に保存）

アイコン・効果音はすべてオリジナル（ゲームの素材は未使用）の非公式ファンツールです。
